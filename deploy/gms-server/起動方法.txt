配置先: /home/h0/ryom13/sushi-battle-server（public_htmlの外）

初回または更新後、サーバーのターミナルで:
cd /home/h0/ryom13/sushi-battle-server
npm ci --omit=dev
HOST=127.0.0.1 PORT=3001 SUSHI_ALLOWED_ORIGINS=https://gms.gdl.jp npm run server

Node.js 20以上を使用します。この配布物には対戦サーバーに必要な依存だけを含めています。
package.jsonとpackage-lock.jsonは必ず同じ配布物のものを一緒にアップロードしてください。

起動後の確認（別のサーバー端末）:
curl -fsS http://127.0.0.1:3001/health
正常時の応答: {"ok":true,"roomTransport":"http-polling-v1"}

公開画面は、同梱のapi.phpから127.0.0.1:3001へ通信します。
release/gms/sushi-battleの中身をpublic_html/sushi-battleへ配置してください。
確認URL: https://gms.gdl.jp/~ryom13/sushi-battle/api.php
正常時の応答: {"ok":true,"transport":"php-polling"}
Webサーバー全体の中継設定を変更する必要はありません。
npm run serverは前面で実行します。ターミナルを閉じて動かす場合は、下記のPM2管理を使います。

自動デプロイ時は、配布用のdeploy.shが専用PM2で管理します。
管理者権限やWebサーバー全体の設定変更は行いません。
PM2管理中に上記npm run serverを重ねて実行しないでください。
SSHを閉じても動作しますが、OS再起動後の自動起動設定は含めていません。
再起動すると進行中の対戦は失われます。
