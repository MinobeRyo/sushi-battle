# すしバトル — 企画と遊び方

更新日：2026年10月7日。改善版の実装を基準にした現行仕様です。公開環境への反映状況は、GitHub Actions の最新実行結果で確認します。

## 1. 企画の核

回転寿司で選んだ寿司をカードにして戦う、ブラウザ向けの対戦ゲームです。寿司を相手に食べさせ、お腹を先にいっぱいにした側が勝ちます。買い物の予算配分と、バトル中に寿司を出す順番の両方を楽しめる構成です。

基本の流れは「3,000円分の寿司を取る → バトルへ進む → 寿司を出して相手に食べさせる → 先に相手を満腹にしたら勝利」です。専門的な説明より、この流れを最初に見せます。

寿司は3Dで皿に載って流れ、カードには対応するイラストを表示します。遊び方はメニュー表に近い大きな文字と短い説明で案内します。カードを選ぶ楽しさと、同じネタを組み合わせるコンボが中心です。

## 2. 遊べるモード

| モード | 内容 |
| --- | --- |
| CPU対戦 | 弱いCPU、通常CPU、挑戦CPUを選んで1人で遊ぶ |
| 2人対戦 | 同じ端末を交代で操作する |
| オンライン対戦 | 部屋を作り、別の端末から部屋コードで参加する |
| カード図鑑 | カードの性能・効果を確認する |
| 改善確認デモ | モデル、注文、防御、遊び方などの変更点を確認する |

## 3. まずは寿司を選ぶ

最初の購入時間は90秒、予算は3,000円です。通常の寿司は回転レーンから選べます。1回の購入時間に集められる寿司は最大20枚で、サイドメニューはこの20枚に含みません。

タブレットの注文枠は、各購入時間につき共通で3回です。特急注文・大将のおすすめ・サイドメニューの購入成功で、それぞれ1回を使います。予算不足などで購入できなかった操作では減りません。通常のベルト上の寿司購入は注文枠を使いません。サイドメニューはベルトから買った場合も1回を使います。

| 購入方法 | 内容 | 注文枠 |
| --- | --- | --- |
| 通常ベルトの寿司 | 表示価格で1枚購入 | 消費なし |
| 特急注文 | 好きな寿司を注文。価格は通常の1.5倍を50円単位で切り上げ | 1回 |
| 大将のおすすめ | 「750円分が500円に！（たまにハズレ）」の3枚セット | 1回 |
| サイドメニュー | 補助効果のある一品を購入 | 1回 |

大将のおすすめは各購入時間に1回だけです。同じ寿司がセット内に含まれる場合があります。通常価格の合計750円になる3枚を抽選し、500円で獲得します。セットの抽選結果は、通常77％、1枚が訳ありになる20％、1枚がレアになる3％です。訳ありは攻撃力半分（端数切り捨て）。レアの「真横を向いたマヨコーン」は2AP・攻撃12です。予算500円と、寿司3枚分の空きが必要です。

## 4. バトルの基本

両者のお腹は0から始まり、100に達した側が負けます。通常攻撃で増えたお腹を、消化やカード効果で減らしながら戦います。

| 基本項目 | 現行ルール |
| --- | --- |
| 初期手札 | 5枚（山札が5枚未満ならその分だけ） |
| 手札上限 | 7枚 |
| 机の上限 | 8枚 |
| 開始AP | 初期状態は両者2。CPUの最初の実手番は3、同端末・オンラインの後攻初手は2 |
| APの成長 | 進行に応じて基本上限が増加し、基本上限は最大10。効果による一時加算あり |
| 通常ドロー | 自分のターン終了時に1枚。コンボで追加あり |
| 消化 | 本人の手番開始時にお腹を減らす。基本量は min(5, 1＋ラウンド) |
| 初期ガリ | 先攻1回、後攻2回 |

自分の番では、APを払って手札から寿司を机へ出します。召喚時の効果やコンボは、その場で処理されます。ターンを終了すると、机の寿司がまとめて相手へ通常攻撃します。

瞬間型の寿司は、その自分ターンの攻撃後に退場します。持続型は、記載された自分のターン数だけ机に残り、毎回攻撃します。持続の残り回数は自分のターン終了時に減ります。防御待機するカードには、別途退場のタイミングがあります。

山札の枚数表示を押すと、自分の現在の山札を確認できます。カード別の残り枚数を確認する画面であり、次に引く順番を示すものではありません。オンラインでも相手の山札や手札は見られません。

## 5. 攻撃を受けるとき

攻撃を受ける画面で、防御カードとガリをまとめて選びます。ガリは対象の攻撃について軽減量を半分・切り捨てで計算します。例えば15ダメージなら7軽減し、8を受けます。連鎖や肉祭りなど、ガリを使えない固定ダメージもあります。

防御カードは、召喚時に予約して自分の通常攻撃を終えると防御待機に変わります。防御枠は1枚です。サバ・イワシ生姜は切れ味を消費して予約し、チーズは枠が空いていれば無料で待機します。相手の攻撃時に使用か温存を選べます。

防御カードの軽減は相手の攻撃可能な寿司1枚へかかります。ランダム対象・選択対象・25％軽減など、カードごとに異なります。使用後、または相手のターン終了時に防御カードは退場します。細かい対象と数値はカード一覧を参照してください。

## 6. 組み合わせて戦う

赤身、巻物、光り物、海鮮、肉寿司にはそれぞれ組み合わせ方があります。軍艦は巻物タグも持つため、巻物コンボの枚数に数えます。

| 組み合わせ | 狙い |
| --- | --- |
| 赤身三種盛り | マグロ・中トロ・大トロを対戦中に出し、追加効果を解放する |
| 巻物 | 同時3枚でドロー強化。同時5枚の間は軍艦の攻撃を1.5倍にする |
| 光り物 | 切れ味を蓄え、攻撃強化・防御・ドローに使う |
| 海鮮 | いか・たこのペアで場の海鮮が再攻撃する |
| 肉寿司 | 生ハムを生成し、生贄や合鴨の強化を組み合わせる |

合鴨寿司は3AP・攻撃2・自分の4ターン持続です。場にいる間、自分の生ハムの攻撃を＋2します。合鴨を複数出しても、この＋2は重なりません。

とびこ軍艦は、出した回数に応じて手札への複製確率が75％→50％→25％→0％に下がります。複製に失敗した召喚も、複製したとびこを出した場合も累計に含みます。

## 7. 追加注文とサイドメニュー

双方の手札と山札がなくなると、追加注文に進みます。追加予算は1,500円、時間は45秒です。机に持続カードが残っていても、手札・山札の条件を満たせば対象になります。注文枠は改めて3回、大将のおすすめも再び1回利用できます。

サイドメニューは各購入時間に1品です。初回に買わなかった場合は後半でも買えます。使い切りの唐揚げ・茶碗蒸しを使用済みの場合は、後の購入時間にもう1品へ買い替えられます。対戦を通してサイド購入は計2回までです。未使用品、永続品、期限が切れたラーメンからの自由な買い替えはできません。

唐揚げは双方のお腹を増やし、茶碗蒸しは自分のお腹と消化停止を回復します。ほかにもドロー・AP・消化・肉寿司を支える一品があります。サイドメニューはバトル中に0APで使用または設置します。

## 8. 今回の見た目と説明の改善

説明文を短くし、遊び方の導入を購入から勝利までの順序へ整理しました。カードの説明は図鑑とバトルで同じ効果文を参照します。

いくら・とびこは色だけの大きな塊を避け、粒で盛りを表現しています。とびこは細かな粒の不規則な配置へ変更しました。ツナ軍艦は淡い赤みのほぐし身、合鴨は薄い身・片側の脂・胡椒を表現しています。横向き軍艦とネタ落ち寿司は、カードイラストと3Dの両方に専用表現があります。巻物の側面と納豆巻きの不要な糸も修正対象に含まれます。

今後のバランス調整では、勝率だけでなく、選ばれないカード、注文枠の使い方、対戦時間、初見で説明が伝わるかを確認します。本書にない将来案は、実装済み仕様として扱いません。
