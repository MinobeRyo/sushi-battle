# すしバトル — ローグライクモード企画（たたき台）

作成日：2026年10月19日。方針と主要な仕組みは決定済み（「✅決定」）。数値はすべて仮で、試遊で調整します。

## 1. ねらい

同じ端末での二人対戦をなくし、その枠に **一人で遊ぶローグライク（Slay the Spire 型）** を入れます。オンライン対戦とCPU対戦はそのまま残します。

今の対戦は「毎回3,000円でデッキを組み直す」一発勝負です。ローグライクでは **デッキを試合をまたいで育てる** 楽しさを足します。

### 方針 ✅決定：インフレ上等

**自分も相手もめちゃくちゃ強くなるほうが楽しい。** 爽快感を最優先にします。

- 炙り・器・限定寿司で、通常対戦では出ない大きな数字を出せるようにする
- 敵も階が進むほど派手に強くなる。大将は通常のルールを超えてくる
- 通常対戦のバランスとは切り離す。ローグライク専用の効果は通常対戦・オンラインに持ち込まない

### 仮タイトル

**寿司はしご** — 一晩で寿司屋をはしごし、各店の大食い客に勝ちながら、最後に名店の大将へ挑む。

## 2. 1回の流れ（ラン）

1. 最初のデッキを受け取り、器を3つから1つ選ぶ（→ 4章）
2. 地図で次に入る店を選ぶ（→ 3章）
3. マスごとの出来事をこなす（対戦・休憩・買い物など）
4. 最後の大将に勝てばクリア。お腹が100になったらラン終了

### 規模 ✅決定：1幕から

初版は **1幕＝8マス＋大将**（20〜30分）。遊べる形を作ってから3幕へ広げます。

## 3. 地図 ✅決定：分岐あり・完全ランダム

下から上へ分岐する道を選んで進みます。マスの種類と出現率は完全ランダムです。ただし最低限の決まりだけ置きます。

- 1マス目は必ず対戦（デッキが弱いまま強敵や買い物に当たらないため）
- 最後（9マス目）は必ず大将
- それ以外は下表の重みで抽選。同じ種類が続くこともある

| マス | 名前 | 重み（仮） | 内容 |
| --- | --- | --- | --- |
| 対戦 | 大食い客 | 45 | 通常CPUと対戦 |
| ？ | ハプニング | 20 | 寿司屋あるある（→ 11章） |
| 強敵 | 常連さん | 15 | 得意技を持つCPU（→ 9章） |
| 休憩 | お茶 | 12 | お腹 −30 か、寿司1枚を炙る |
| 買い物 | 回転レーン | 8 | 寿司を買う・下げてもらう（→ 10章） |
| ボス | 大将 | 最後のみ | 専用ルールの最強CPU |

道は3本で、隣の道へ斜めに移れる箇所をランダムに作ります。

## 4. 最初のデッキ ✅決定：固定10枚＋系統3枚

固定の汎用10枚に、5系統から1つ選んだ3枚を足した **13枚** で始めます。

**固定10枚（仮）**：たまご×2、いなり×2、サーモン、ツナサラダ軍艦×2、コーン軍艦、チーズ、えびアボカド

| 系統 | 追加3枚（仮） |
| --- | --- |
| 赤身 | マグロ、中トロ、大トロ（最初から赤身三種盛りを狙える） |
| 巻物・軍艦 | かっぱ巻き、納豆巻き、いくら軍艦 |
| 光り物 | アジ、イワシ、コハダ |
| 海鮮 | いか、たこ、えび |
| 肉寿司 | 牛タン寿司、カルビ寿司、焼肉寿司、和牛にぎり（4枚。生ハムを増やすカードに、使うカードが追いつくよう和牛を足した） |

選んだ系統は報酬の出やすさに影響します（→ 6章）。開始画面で系統を選ぶと、その初期デッキ13枚が効果つきで並びます。

### 開始時の器 ✅決定：3つから1つ

系統を選んだ直後、地図に入る前に、**ランダムな器3つから1つ** を選んで受け取ります（スキップなし）。出し方は常連さんの報酬と同じで、1つは選んだ系統の器、格は並60%・上30%・特上10%。通常の器18種からだけ出し、大将の器（代償つき）は出しません。3択は保存され、選ぶ前に中断しても同じ3択で再開します。

## 5. 持ち越すもの

| 項目 | ラン中の扱い |
| --- | --- |
| デッキ | 試合をまたいで持ち越す。報酬・買い物・ハプニングで増減 |
| お腹 | HPの代わりに持ち越す。100でラン終了 |
| 持ち金 | 対戦の報酬で増え、買い物で使う。開始時0円 |
| 器 | 集めた分だけ持てる（→ 8章） |
| サイドメニュー | 1枠を持ち越す。常連さんの報酬・買い物で入手・交換 |
| ガリ | 毎試合1個に戻る。器・ハプニングで増える |

### お腹の持ち越し ✅決定

試合の終わりのお腹を **半分（切り捨て）** にして次の試合へ持ち越します。休憩でさらに −30。

### 手札とドロー ✅決定：最初の手札6枚・毎ターン2枚

通常の5枚・毎ターン1枚では、13枚の安いデッキだと手札がすぐ尽きます（試算：1軒目のターン終了時の79%が手札0）。はしごの試合では自分だけ6枚・毎ターン2枚にします（同試算で19%、1軒目の勝率47%→94%）。CPU側は変えません。

### 手札上限 ✅決定：自分だけ10枚

通常は7枚です。毎ターン2枚引くと、焼肉寿司などで増えた生ハムを置く余地がなくなるため、はしごでは自分だけ10枚にします（2026年10月22日、試遊で「肉寿司が回らない」とのことで決定）。CPU側は7枚のままです。

### 初期AP ✅決定：自分だけ3から

通常は両者2から始まります。はしごでは自分だけ3から始め、以降も毎ターン+1（上限10）にします。2026年10月21日、試遊で「序盤に出せる寿司が少なすぎる」とのことで決定しました。CPU側は変えません。

### 試合中の山札切れ ✅決定：おかわり

手札と山札が尽きたら、**使った寿司を山札に戻してシャッフル** します。追加注文はなし。エンジンに「使った寿司の記録」を足します。

## 7. 炙り ✅決定：全種に専用の強化

お茶マスで1枚を **炙り** にできます。1枚につき1回まで。名前に「炙り」が付き、カードと3Dモデルに焼き目と炎の縁を付けます。どの寿司も「別物になった」と感じるくらい強くします。

生ハムは炙れません。訳ありの寿司を炙ると、訳ありが直って炙り版になります。

## 8. 器（レリック） ✅決定：系統を壊すシナジー型

サイドメニューとは別枠で、**何個でも持てる永続アイテム** です。単純な底上げではなく、**特定の系統とかみ合うと壊れたように強くなる** ものを中心にします。「拾った器を見てデッキを寄せる」判断がランの面白さになります。

- 通常の器18種（各系統3種＋汎用3種）、系統をまたぐ **相盛りの器** 6種、代償つきの **大将の器** 7種、計31種
- 入手：ラン開始時（3つから1つ → 4章）、常連さんの報酬（3つから1つ。うち1つは選んだ系統の器）、ハプニング
- 報酬で出る格の確率（仮）：並60%・上30%・特上10%。同じ器は1ランに1つまで

## 9. ローグライク専用の特殊効果 ✅決定：たくさん入れる

通常対戦にない効果を、ラン専用の要素として足します。通常対戦・オンラインには持ち込みません。

### 9-0. 新しい仕組み ✅決定：今の寿司バトルにない効果を足す

| 仕組み | 内容 | 例 |
| --- | --- | --- |
| 複製 | 机・手札・山札の寿司をコピーする。複製品は名前に「（おかわり）」が付き、試合が終わると消える | 机の寿司を1枚コピー、手札の寿司を山札へ2枚コピー |
| AP還元（お釣り） | 出した瞬間にAPが戻る。条件付きで差し引き0APや黒字にもなる | 出すとAP+2、3枚目以降は0AP |

## 10. 敵の強さ ✅決定：デッキと満腹ラインで調整

序盤の敵は **満腹ライン（負けるお腹の量）を100より低く** します。初版の「相手の初期お腹を高くする」案は、画面上で100まで食べさせる必要があるように見えて重かったため、2026年10月19日に置き換えました。

| 軒 | 大食い客のデッキ | 敵の満腹ライン | その他 |
| --- | --- | --- | --- |
| 1〜3 | 最弱CPU | 50 → 55 → 60 | — |
| 4〜6 | 5系統CPUからランダム | 60 → 65 → 70 | 敵デッキの2割が炙り版 |
| 7〜8 | 5系統CPU | 75 → 80 | 敵デッキの4割が炙り版 |
| 大将 | 挑戦CPU | 150 | 専用ルール（9-3）、デッキの4割が炙り版 |

大食い客の満腹ラインには、顔ぶれの癖（±）が加わります（9-4）。

焼肉寿司・天ぷらなどの「相手のお腹○以上」は、**相手の満腹ラインに対する割合** で判定します（例：満腹ライン50の敵のお腹25は「50」扱い）。2026年10月22日、試遊で「焼肉寿司が回らない」（満腹ライン50の敵には「50以上」が成立しない）とのことで決定しました。

常連さんは同じ軒の大食い客より1段強いデッキ＋得意技。

試算（貪欲に強い寿司から出すだけの自動操作、各200戦）：1軒目99%、3軒目93%、4軒目約30%。4軒目からの段差は、第2段の炙り・器でプレイヤー側を強くして埋める想定です。
