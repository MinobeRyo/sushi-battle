# 寿司デッキバトル 企画メモ

## 概要
寿司の回転レーンからお皿を取得してデッキを構築し、相手と対戦するカードゲーム風Webアプリ。
- プラットフォーム：Web（React + TypeScript）
- 対戦モード：CPU対戦 / 二人対戦（同端末）
- オンライン対戦はv2以降

## コアループ
1. ドラフトフェーズ：回転レーンのお皿を軍資金で購入してデッキ構築
2. バトルフェーズ：デッキからカードを引いて使用、お腹ゲージを削り合う

## ゲームリソース
**お腹ゲージ（HP）**：初期値100、満腹度で上昇、攻撃で減少、0で負け
**軍資金**：初期値3000円、ドラフトで消費、残額はバトルで追加注文に使用
追加注文：2倍料金でレーンにないお皿を注文できる

## ドラフトフェーズ
レーン3本：特急（速い・高価格）/ 普通（中速）/ 残り物（遅い・特殊効果）
取得ルール：ターン制・デッキ上限15枚・終了条件は両者パス or 10ターン

## カードデータ構造
```typescript
type Card = {
  id: string
  name: string            // "ポン酢タコ"
  base: string            // "タコ" ← コンボ判定に使う
  topping: string | null  // "ポン酢" | null
  price: number
  attack: number
  fullness: number
  effect: string | null
}
```
設計思想：同じネタ × 調理法/薬味 = 別カード（例：タコ / タコ大葉 / ポン酢タコ / 塩タコ）

## コンボ・ビルド戦略軸
- 赤身ビルド：マグロ系3枚以上 
- 巻物ビルド：巻き物5枚以上 
- 光り物ビルド：大葉トッピング3枚 → 切れ味×1.5倍
- 高級ビルド：500円皿3枚以上 
みたいな感じ。

## 薬味・サイドメニュー
薬味スロット2枠：あがり（デバフ全解除）/ ガリ（相手攻撃半減）/ サビ（次攻撃×1.5）
サイドメニュースロット1枠：味噌汁（開始時お腹+5）/ 茶碗蒸し（毎ターンお腹+1）

## 技術スタック
React + TypeScript / Tailwind CSS / Framer Motion / Zustand / Supabase（将来）

## MVP範囲
- ドラフト（1レーン・10種類）
- バトル（基本攻撃のみ）
- CPU対戦（ふつうのみ）
- 同端末二人対戦
v2以降：特殊効果・追加注文・トッピング差分カード・オンライン対戦
